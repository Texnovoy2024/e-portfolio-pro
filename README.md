# E-Portfolio Pro

O'quvchilar uchun elektron portfolio tizimi.

## Xususiyatlar

- 📝 Portfolio yaratish va tahrirlash
- 🎓 Sertifikatlar, yutuqlar, ko'nikmalar
- 📊 Akademik natijalar va GPA hisoblash
- 💼 Ish tajribasi va ta'lim tarixi
- 🌐 Tillar va maqsadlar
- 📄 PDF va JPG formatda export
- 🔗 Portfolio ulashish
- 👨‍🏫 O'qituvchi paneli
- 📥 CSV import

## Texnologiyalar

- HTML5
- CSS3 (Tailwind CSS)
- JavaScript (Vanilla)
- LocalStorage
- html2canvas
- jsPDF
- QRCode.js

## Deploy

Vercel'da deploy qilingan: [E-Portfolio Pro](https://your-domain.vercel.app)

## Ishga tushirish

1. Loyihani yuklab oling
2. `index.html` ni brauzerda oching
3. Yoki Vercel'ga deploy qiling
